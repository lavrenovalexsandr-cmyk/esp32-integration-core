# ESP32 OTA Manager для Home Assistant

Пользовательская интеграция Home Assistant для обнаружения ESP32-устройств через MQTT, отображения их состояния и управления OTA-обновлением прошивки, перезагрузкой и полным сбросом настроек.

## Содержимое репозитория

- `custom_components/esp32_ota` — интеграция Home Assistant и сервисы управления устройствами.

Lovelace-карточки вынесены в отдельный репозиторий: [esp32-card](https://github.com/lavrenovalexsandr-cmyk/esp32-card).

## Требования

- Home Assistant с настроенной и подключённой официальной интеграцией MQTT.
- ESP32 прошивка, реализующая соответствующие MQTT-топики идентификации устройства и OTA.
- Для команд перезагрузки и полного сброса требуется поддержка топиков `system/restart` и `system/factory_reset` в установленной прошивке.

## Доступность устройства

Интеграция отдельно отслеживает MQTT availability по топику `esp32/<DEVICE_ID>/availability` (retained `online` / `offline`). OTA-статус не используется для определения доступности. При неожиданном отключении ESP32 брокер публикует retained `offline` через MQTT Last Will, настроенный в `platform_ha` Core. OTA-карточка показывает «Не в сети» независимо от последнего результата обновления.

## Установка через HACS

1. Откройте **HACS → Интеграции**.
2. Откройте меню в правом верхнем углу и выберите **Пользовательские репозитории**.
3. Добавьте репозиторий:
   `https://github.com/lavrenovalexsandr-cmyk/esp32-mqtt-ha-integration`
4. В качестве категории выберите **Integration** и подтвердите добавление.
5. Найдите **ESP32 OTA Manager** в HACS и установите интеграцию.
6. Перезапустите Home Assistant.
7. Откройте **Настройки → Устройства и службы → Добавить интеграцию** и добавьте **ESP32 OTA Manager**.
8. Установите Lovelace-карточки отдельно из репозитория [esp32-card](https://github.com/lavrenovalexsandr-cmyk/esp32-card).

После установки через HACS файлы интеграции будут размещены в `custom_components/esp32_ota`. При выходе новых версий обновление можно выполнять из HACS.

### Ручная установка

Если HACS не используется, скопируйте каталог `custom_components/esp32_ota` в `<HA config>/custom_components/esp32_ota`, перезапустите Home Assistant и добавьте интеграцию через **Настройки → Устройства и службы → Добавить интеграцию**.

## Сервисы Home Assistant

Интеграция предоставляет следующие сервисы домена `esp32_ota`:

| Сервис | Параметры | Назначение |
|---|---|---|
| `esp32_ota.update` | `device_id`, `url`, необязательно `token` | Запуск OTA-обновления выбранного устройства |
| `esp32_ota.restart` | `device_id` | Обычная перезагрузка выбранного ESP32 |
| `esp32_ota.factory_reset` | `device_id` | Полный сброс пользовательских настроек выбранного ESP32 |
| `esp32_ota.save_token` | `token` | Сохранение GitHub-токена |

Для сервисов управления `device_id` — 12-значный аппаратный ID ESP32 в шестнадцатеричном формате. Устройство должно быть обнаружено интеграцией по MQTT.

## MQTT-протокол

Интеграция обнаруживает устройства по retained-сообщениям с их идентификацией:

- Топик: `esp32/<12-uppercase-hex-id>/device/info`
- Пример содержимого:

```json
{"id":"AABBCCDDEEFF","name":"Kitchen","model":"ESP32-C3"}
```

### OTA-обновление

Команда OTA-обновления (QoS 1, без retained):

- Топик: `esp32/<id>/ota/update`
- Содержимое:

```json
{"url":"https://.../firmware.bin","github_token":"<optional>"}
```

Статус OTA-обновления:

- Топик: `esp32/<id>/ota/status`
- Пример содержимого:

```json
{"status":"online|downloading|installing|rebooting|success|error","progress":0,"message":"..."}
```

### Команды управления устройством

Команды отправляются адресно выбранному ESP32, с QoS 1 и без retained:

| Действие | MQTT-топик | Payload |
|---|---|---|
| Перезагрузка | `esp32/<id>/system/restart` | `1` |
| Полный сброс | `esp32/<id>/system/factory_reset` | `1` |

Обычная перезагрузка не должна изменять настройки устройства. Factory Reset должен обрабатываться прошивкой и удалять пользовательские настройки в соответствии с её реализацией. Интеграция Home Assistant отправляет команду, но сама не очищает память ESP32. Убедитесь, что установленная версия прошивки поддерживает эти MQTT-команды.

При успешной отправке сервис подтверждает публикацию команды в MQTT; это не является подтверждением завершения перезагрузки или сброса самим устройством.

Принимающая часть OTA на стороне прошивки поддерживается в отдельном проекте ESP32: [esp32_mqtt_xiaomi_lywsd03](https://github.com/lavrenovalexsandr-cmyk/esp32_mqtt_xiaomi_lywsd03). Прошивка загружает файл по HTTPS, записывает его в неактивный OTA-раздел и передаёт состояние обновления через MQTT.

## GitHub-токен для приватных релизов

OTA-карточка позволяет указать необязательный GitHub-токен. Интеграция может сохранить его в `secrets.yaml` Home Assistant под именем `esp32_ota_github_token`.

При сохранении существующие строки и комментарии файла не удаляются. Файл записывается атомарно с правами доступа только для владельца. Токен, введённый непосредственно в форме обновления, имеет приоритет над сохранённым токеном для этого запроса.

Токен передаётся только API-адресам GitHub. Его нельзя пересылать на внешние CDN-серверы, с которых загружается файл прошивки.
